# HIA-uView-Tool

This workspace contains the private, development-time CLI that supports HIA-uView-UI verification and adoption metadata. It is not published and has no UI-runtime export. The pre-release command, configuration, privacy, and runtime-isolation boundary is documented in the repository [Tool contract](../docs/tool.md).

The implementation provides read-only `doctor`, `check contract`, `check adoption`, `inspect components`, `inspect compatibility`, `inspect api-compatibility`, and `inspect migration-actions` commands. `inspect compatibility` reports bounded platform evidence; `inspect api-compatibility` reports the separate versioned API/migration inventory; `inspect migration-actions` reads only an explicitly declared, matrix-cross-checked action packet and never scans or changes a consumer application. The Tool reads only declared, repository-local JSON metadata; it neither scans application or component source nor runs scripts, builds, package managers, Git, network requests, an upstream checkout, or DevTools. HIA-uView-Tool must not become an undeclared UI runtime dependency or import business-framework internals. Business-oriented helpers belong in the separate HIA-uView-Biz repository, not here. Source follows the bilingual [Documentation Sys contract](../docs/documentation.md) from its first line.
