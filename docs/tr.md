# UTr component contract / UTr 组件契约

> Status / 状态：Private pre-release view-based table-row projection.
> 状态：私有预发布 view-based 表格行投影。

`UTr` composes caller cell slots. With explicit `clickable`, an enabled row reports one transparent `select` value; it does not own a record, sort rows, navigate, or measure geometry.

`UTr` 组合调用方 cell slot。显式 `clickable` 时，已启用行报告一个透明 `select` 值；它不拥有记录、不排序行、不导航，也不测量几何。

The root namespace is `u-tr` and consumes `--u-comp-tr-*`. Its `row` role is a bounded assistive marker only.

根命名空间为 `u-tr`，消费 `--u-comp-tr-*`。其 `row` role 只是受限辅助标记。
