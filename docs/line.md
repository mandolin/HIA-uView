# ULine component contract / ULine 组件契约

`ULine` renders a horizontal or vertical local divider with bounded percentage length. It expresses no workflow, permission, or business relation.

`ULine` 呈现受限百分比长度的水平或垂直局部分隔线。不表达流程、权限或业务关系。

| Prop / 属性 | Type / 类型 | Default / 默认值 |
| --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `color` | `string` | `''` |
| `length` | `number` (0–100) | `100` |

Consumes `--u-comp-line-*`; no platform service is used. / 消费 `--u-comp-line-*`；不使用平台服务。
