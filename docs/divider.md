# UDivider component contract / UDivider 组件契约

> Status / 状态：Private pre-release local divider.
> 状态：私有预发布局部分隔。

`UDivider` renders finite horizontal/vertical line geometry with optional caller text or slot. It infers no page hierarchy, section semantics, or dynamic layout.

`UDivider` 呈现有限的水平/垂直线条几何，可选调用方文字或 slot。它不推断页面层级、区块语义或动态布局。

Props are `direction`, `tone`, and `text`; the root namespace is `u-divider` and consumes `--u-comp-divider-*`.

属性包括 `direction`、`tone` 和 `text`；根命名空间为 `u-divider`，消费 `--u-comp-divider-*`。
