# UTransition component contract / UTransition 组件契约

`UTransition` wraps caller slot content with finite CSS `mode`, bounded millisecond `duration`, and caller-owned `visible`. It uses no JavaScript timer, measurement, lifecycle service, or cross-root movement.

`UTransition` 使用有限 CSS `mode`、受边界保护的毫秒 `duration` 与调用方拥有的 `visible` 包装调用方 slot 内容。它不使用 JavaScript timer、测量、生命周期服务或跨根移动。

This constrained surface does not claim complete upstream transition lifecycle compatibility.

这个受限表面不声明完整上游 transition 生命周期兼容性。
