# USection component contract / USection 组件契约

`USection` presents a title, subtitle, right action text or slots, and local `right-click`. It infers no industry field, route, or data source.

`USection` 呈现标题、副标题、右侧 action 文字或插槽，并报告局部 `right-click`。不推断行业字段、路由或数据源。

| Prop / 属性 | Type / 类型 | Default / 默认值 |
| --- | --- | --- |
| `title` / `subTitle` / `rightText` | `string` | `''` |

Consumes `--u-comp-section-*`; caller owns action meaning. / 消费 `--u-comp-section-*`；action 含义由调用方拥有。
