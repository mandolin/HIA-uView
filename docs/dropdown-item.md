# UDropdownItem component contract / UDropdownItem 组件契约

`UDropdownItem` presents a finite `value`/`label` and reports `select`; under `UDropdown`, it delegates the value to the parent's controlled context.

`UDropdownItem` 呈现有限 `value`/`label` 并报告 `select`；置于 `UDropdown` 下时，将值委托给父级受控 context。

| Prop / 属性 | Type / 类型 | Default / 默认值 |
| --- | --- | --- |
| `value` | `string \| number` | `''` |
| `label` | `string` | `''` |
| `disabled` | `boolean` | `false` |

It executes no command or navigation. / 不执行命令或导航。
