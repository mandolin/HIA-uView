# UTopTips component contract / UTopTips 组件契约

`UTopTips` displays caller-owned top feedback with finite tone and optional labeled `close` intent. It does not auto-dismiss, time, push, or queue feedback.

`UTopTips` 显示调用方拥有的顶部反馈、有限 tone 和可选带文字的 `close` 意图。它不自动消失、不计时、不推送或排队反馈。

Finite layering is tokenized and local; the component is not a global toast service.

有限层级使用 token 并保持局部；组件不是全局 toast 服务。
