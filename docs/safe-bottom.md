# USafeBottom component contract / USafeBottom 组件契约

`USafeBottom` reserves caller-specified, bounded bottom spacer height. It does not inspect device inset, notch, page scroll, or native container.

`USafeBottom` 预留调用方指定且受边界保护的底部占位高度。它不检查设备 inset、刘海、页面滚动或原生容器。

Its default height is zero so no platform assumption is made when the caller supplies nothing.

默认高度为零，因此调用方未提供值时不会作出平台假设。
