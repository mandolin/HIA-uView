# UTd component contract / UTd 组件契约

> Status / 状态：Private pre-release static view-based table cell.
> 状态：私有预发布静态 view-based 表格单元格。

`UTd` presents caller `text` or slot content with bounded `start`/`center`/`end` alignment. It does not format domain values, infer types, edit, or write back.

`UTd` 以受限 `start`/`center`/`end` 对齐呈现调用方 `text` 或 slot 内容。它不格式化领域值、不推断类型、不编辑，也不写回。

The root namespace is `u-td` and consumes `--u-comp-td-*`. Its `cell` role is an assistive marker, not a native table guarantee.

根命名空间为 `u-td`，消费 `--u-comp-td-*`。其 `cell` role 是辅助标记，不是原生表格保证。
