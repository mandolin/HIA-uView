# UNoNetwork component contract / UNoNetwork 组件契约

`UNoNetwork` presents caller-declared visibility, title, description, and optional labeled `retry` intent. It performs no connectivity detection, device-state read, network request, or recovery.

`UNoNetwork` 呈现调用方声明的可见性、标题、说明和可选带文字的 `retry` 意图。它不执行连接检测、设备状态读取、网络请求或恢复。

The text-first panel intentionally excludes upstream illustration assets and makes no claim about actual network availability.

文字优先面板刻意排除上游插图资产，也不声明真实网络可用性。
