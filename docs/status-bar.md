# UStatusBar component contract / UStatusBar 组件契约

`UStatusBar` reserves caller-specified, bounded top spacer height. It does not query system information, device status-bar height, safe area, or native window settings.

`UStatusBar` 预留调用方指定且受边界保护的顶部占位高度。它不查询系统信息、设备状态栏高度、安全区或原生窗口设置。

It is a presentation spacer, not a system-bar integration.

它是展示占位，而不是系统栏集成。
