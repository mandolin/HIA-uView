# UTh component contract / UTh 组件契约

> Status / 状态：Private pre-release static view-based header cell.
> 状态：私有预发布静态 view-based 表头单元格。

`UTh` presents caller `label` or slot content with bounded `start`/`center`/`end` alignment. It does not sort, filter, infer a field, or establish a data schema.

`UTh` 以受限 `start`/`center`/`end` 对齐呈现调用方 `label` 或 slot 内容。它不排序、不筛选、不推断字段，也不建立数据 schema。

The root namespace is `u-th` and consumes `--u-comp-th-*`. Its `columnheader` role does not replace target-platform accessibility evidence.

根命名空间为 `u-th`，消费 `--u-comp-th-*`。其 `columnheader` role 不替代目标平台无障碍证据。
