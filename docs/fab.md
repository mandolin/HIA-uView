# UFab component contract / UFab 组件契约

`UFab` renders a caller-visible, labeled action with finite local position markers and emits `click` only while enabled. It does not drag, expand a menu, navigate, or execute business behavior.

`UFab` 渲染调用方可见、带文字的操作控件，具有有限本地位置标记，并仅在启用时 emit `click`。它不拖拽、不展开菜单、不导航，也不执行业务行为。

Its CSS remains in normal caller layout flow; it is not a global fixed-layer service.

其 CSS 保持在调用方正常布局流中；它不是全局固定层服务。
